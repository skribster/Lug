Welcome, dear user, to the Lug language. I'm glad you're here! 
This guide aims to teach you the basic core concepts of Lug, and
all of its quirks and features.

## Your First Program

To follow tradition, let's make a basic `Hello, world!` program.
First, make sure you got an installation of Lug somewhere. In the
available [GitHub releases](https://github.com/skribster/Lug/), 
there should be an executable in bin/ that containts the standalone
Lug interpreter.

Type this in a separate file named program.lug, or use the REPL.

```
print("Hello, world!")
```
This line will print the string "Hello, world!" into the console. You
can run it in the interpreter like this.

```
path/to/lug.exe program.lug
```

Nice! You just created your first ever Lug program.
