Lug

A simple, embeddable, easy-to-learn language that plays heavily into the 'box' metaphor.

About

Take Lua's simple syntax and mix it with Python's intuitiveness.

Lug is based on the 'box' metaphor commonly used to teach beginner programming concepts, with the language's semantics aiming to be predictable and consistent for newcomers to easily pick up.

Why Lug?

  • Lug is easy to follow.

    Lug is designed to feel approachable without making your code's behavior a mystery. Its central 'box' metaphor gives beginners and newcomers a simple and concrete way to visualize how values are passed around. All with a friendly and readable syntax.

  • Lug is embeddable.

    Lug is built in the widely-available C++17 standard, making it embeddable in most modern C++ projects. Any application can create a Lug virtual machine, utliizing its friendly C++ API, and run Lug code without relying on the standalone interpreter.

  • Lug is small.

    Lug aims to keep its language and runtime focused rather than overwhelming users with a large, complicated system. The source code is also written in plain C++ without much of the complicated or obscure syntax that may plague other C++ projects today.
