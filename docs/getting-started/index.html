Getting Started

Try the Playground!

Run your first line of Lug code in the playground! It's just in your browser, and you don't need to install anything on your computer.

Embed Lug!

Experiment with Lug by embedding it in your own C++ project! Lug is designed to be a lightweight scripting language for all sorts of high-level tasks. Read below to get a brief guide on how to include Lug in your project, or read the embedding guide for a deep dive.

Including Lug

Including Lug is as easy as installing one of the binaries from GitHub and linking to that. You can also build Lug straight from the source and incorporate it that way. All the source code and releases are available on the Lug GitHub repository.
