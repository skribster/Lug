Lug

A simple, embeddable, easy-to-learn language that leans heavily into the 'box' metaphor.

Get Started!

About

Take Lua's simple syntax and mix it with Python's intuitiveness. Lug is based on the 'box' metaphor commonly used to teach beginner programming concepts, with the language's semantics aiming to be predictable and consistent to newcomers. 

print("Hello, world!")

box Dog <- thing
Dog.new <- function(name, age, sound)
    box newDog <- thing of Dog
    newDog.name <- name
    newDog.age <- age
    newDog.sound <- sound

    return newDog
end

Dog.speak <- function(shared self)
    print(self.name + " says " + self.sound + "!")
end

box buddy <- Dog.new("Buddy", 8, "bark")
buddy:speak()

Why Lug?

  • Lug is easy to follow.

    Lug is designed to feel approachable without making your code's behavior a mystery. Its central 'box' metaphor gives beginners and newcomers a simple and concrete way to visualize how values are passed around. All with a friendly and readable syntax.

  • Lug is embeddable.

    Lug is built in the widely-available C++17 standard, making it embeddable in most modern C++ projects. Any application can create a Lug virtual machine, utliizing its friendly C++ API, and run Lug code without relying on the standalone interpreter.

  • Lug is small.

    Lug aims to keep its language and runtime focused rather than overwhelming users with a large, complicated system. Lug's binaries are less than half of a megabyte. The source code is also written in plain C++ without too much of the complicated or obscure syntax that may plague other C++ projects today.

  • Lug is powerful.

    Lug is small, but that doesn't stop it from being powerful. Although Lug is prototypal in its core design, it supports a multitude of paradigms while allowing more complex ways to interact with your program. For instance, there is a simple but powerful structure in Lug called a 'thing', but it lets you have complex metaprogramming and even a familiar OOP structure.
